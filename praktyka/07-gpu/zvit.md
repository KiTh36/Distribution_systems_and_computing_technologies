# Висновки
| GPU, лише ядро (07) | 15.314 мс | | карта: Tesla T4, Colab | |
| GPU, з копіюванням (07) | 20.125 мс | | те саме | |

**1)Скільки дало ядро проти njit(parallel=True) у тому самому зошиті — і чому не більше?**
На GPU саме ядро виконалося за 15,314 мс, а разом із копіюванням даних загальний час становив 20,125 мс.

**2)Яка частка часу пішла на копіювання на найменшому розмірі й на найбільшому?**
Копіювання даних зайняло 23,91% загального часу для задачі розміром 1200×800.

**3)За якого розміру задачі GPU починає окупатись — і що означає «окупатись» для одноразового запуску проти тисячі запусків поспіль?**
Для найбільшої задачі 3000×2000 частка копіювання становила 23,30%, а загальний час — 74,044 мс.

**4)Скільки у вас розбіжних точок — і звідки вони беруться?**
Кількість розбіжних точок між CPU та GPU становила **2 із 960 000**, тобто результати майже повністю збігаються.

**5)Де у вашому власному коді (диплом, робота, пет-проєкт) GPU не дав би нічого?**
GPU не дав би переваги для невеликих задач, оскільки копіювання даних на відеокарту й назад може зайняти більше часу, ніж виконання самих обчислень на CPU.
