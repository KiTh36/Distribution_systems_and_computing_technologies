# Заміри продуктивності потоків

## Обчислення: Mandelbrot

Для послідовної версії виконано три прогони. За базовий час взято мінімальний результат.

| Потоків | Прогін 1 | Прогін 2 | Прогін 3 | Мінімум | Прискорення |
| ------- | -------: | -------: | -------: | ------: | ----------: |
| 1       |     6.63 |     6.59 |     6.59 |    6.59 |       ×1.00 |
| 2       |     6.62 |     6.59 |     6.51 |    6.51 |       ×1.01 |
| 4       |     6.66 |     6.65 |     6.67 |    6.65 |       ×0.99 |
| 8       |     6.75 |     6.92 |     6.99 |    6.75 |       ×0.98 |
| max     |     7.03 |     6.91 |     7.02 |    6.91 |       ×0.95 |

`max = os.cpu_count() = 4`.

Для кожної потокової версії перевірено відповідність результату послідовній версії за допомогою `assert result == base`.

Завантаження CPU для 8 потоків: **1.01**.

## Очікування: 32 × 0,5 с

Послідовна версія виконує 32 виклики `time.sleep(0.5)`. Для потокових варіантів використовується `ThreadPoolExecutor`. Для кожної кількості потоків виконуються три прогони.

| Потоків | Прогін 1 | Прогін 2 | Прогін 3 | Мінімум | Прискорення |
| ------- | -------: | -------: | -------: | ------: | ----------: |
| 1       |          |        — |        — |         |       ×1.00 |
| 2       |          |          |          |         |             |
| 4       |          |          |          |         |             |
| 8       |          |          |          |         |             |
| max     |          |          |          |         |             |

`max = os.cpu_count() = 4`.

Для кожної потокової версії перевіряється відповідність результату послідовній версії за допомогою `assert result == base_wait`.
